# Concept Projects — сайт

Статический сайт (без сборки). Откройте `index.html` через любой веб-сервер, например:

    python3 -m http.server 5173

## Что внутри
- `index.html` — главная страница
- `project.html?p=<slug>` — страница проекта (одна на все 12 проектов)
- `assets/css/style.css` — стили (цвета бренда в `:root`)
- `assets/js/data.js` — **контент**: проекты, описания, материалы, переводы RU/UZ/EN
- `assets/js/core.js` — общее: языки, плавная прокрутка, курсор, переходы между страницами
- `assets/js/app.js` — главная: заставка, галерея, форма, глобус
- `assets/js/project.js` — страница проекта: палитра из фото, детали, следующий проект
- Первый экран — фильм во весь экран, который «проигрывается» прокруткой (кадры проектов или видео из `CP_REEL_VIDEO`)
- Галерея 12 проектов — 3D-«коридор»: работы пролетают мимо при прокрутке
- `assets/js/fx.js` — WebGL-эффект фото (жидкая линза, RGB-сдвиг, изгиб при прокрутке)

Добавить проект: положите фото в `assets/img/` и добавьте запись в `CP_PROJECTS` в `data.js`.
- `assets/img/` — логотип, фото проектов (из Instagram, 512px), фото основателя (150px)

## Что нужно от клиента перед запуском
1. Фото проектов в высоком разрешении (сейчас 512px из Instagram) — заменить `p01…p12.jpg`.
2. Портрет Умара в высоком разрешении — заменить `owner.jpg`.
3. Логотип в векторе (сейчас перерисован вручную по образцу из профиля).
4. Куда отправлять заявки (Telegram-бот, CRM, e-mail) — в `app.js` есть событие `cp:lead`.
5. Проверить тексты, названия проектов и список стран/фабрик.

## Перед запуском обязательно
- **Отзывы** (секция «Отзывы» в `index.html`, ключи `r1…r3` в `data.js`) — это примеры-заглушки.
  Заменить реальными отзывами клиентов (раздел «Отзывы» в Instagram @umar_concept_).
- **FAQ и сроки в «Процессе»** — согласовать с Умаром (цены, сроки, страны).
- **Фильм (Showreel)** — чтобы вместо слайд-шоу играло настоящее видео, положите файл в
  `assets/video/reel.mp4` и укажите путь в `CP_REEL_VIDEO` в конце `data.js`.
- Языки: RU, UZ, EN, KZ, TR. Если перевода нет, KZ показывает русский, TR — английский.
